# Kali-Unix-LIA
## What is Kali Linux
Kali is a Linux distribution based from Debian. Because it is, it uses the same package manager (Advanced Package Tool, or APT). Unlike Debian, it is primary used to penetration test networks, find vulnerabilities and monitor incoming and outgoing traffic. Because of that, it is not recommended to use it as your daily driver.

Kali is recommended for system administrators, those who want to claim bug bounties and cybersecurity analysts.
## How to install
- Install the distribution ISO from the official site : [Kali](https://www.kali.org/get-kali/#kali-platforms)
- Use a tool to make your USB bootable, such as [Ventoy](https://www.ventoy.net/en/index.html)
  - Format the USB using the tool and install the the ISO on it.
- Go to the boot menu on the device you want to install it on then select the USB
- Partition your storage unit and install using the ISO booted from the USB
## What does Kali offer
- Kali comes preinstalled with many tools, such as [John the ripper](https://www.openwall.com/john/), [nmap](https://nmap.org/), [donut](https://github.com/thewover/donut), and many more.

## Why chose Kali over other similar distributions
- Kali has a lot of documentation and has a big community.
- It has built a solid reputation.
- Since it is based on Debian, it has less bloat and is stable
